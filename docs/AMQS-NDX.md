# AMQS-NDX — 나스닥 4-Factor 모멘텀 대시보드

> AMQS-BIO(바이오·제약 33종 · XBI 레짐)의 **나스닥판**. 벤치마크를 XBI → **QQQ**로,
> 임상 갭 필터를 **실적 갭 필터**로, 거시 배점 25% → **10%**로 바꾼 구성이다.
> 참고 원본: `vibequant.cc/research/bio/` · `gameworkerkim/vibe-investing` AMQS-BIO 리포트.

```bash
python cli.py nasdaq                 # 터미널 요약 (4시간 캐시)
python cli.py nasdaq --serve         # http://127.0.0.1:8765 대시보드
python cli.py nasdaq --out output/amqs-ndx.html   # 정적 HTML로 저장
python cli.py nasdaq --refresh       # 캐시 무시하고 재계산
python cli.py nasdaq --demo          # 네트워크 없이 레이아웃만 확인(합성 데이터)
python cli.py nasdaq --json          # 스냅샷 원본 JSON
```


## 2. 레짐 — QQQ

| 레짐 | 조건 | 투자비중 |
|------|------|----------|
| Risk-On | QQQ ≥ 200MA **그리고** VIX < 28 | 100% |
| Neutral | 둘 중 하나만 충족 | 60% |
| Risk-Off | 둘 다 불충족 **또는** VIX ≥ 35 | 25% |
| 급락 가드 | QQQ 5일 수익률 ≤ −7% | 한 단계 강등 |

레짐은 종목 점수보다 **먼저** 적용된다. 점수가 아무리 높아도 Risk-Off면 총 비중은 25%다.

## 3. 4-Factor 채점 (100점)

각 지표는 절대값이 아니라 **유니버스 내 백분위**로 환산해 배점을 곱한다.
시장 전체가 밀려도 상대 서열은 유지된다.

| 팩터 | 배점 | 구성 |
|------|------|------|
| 모멘텀 | 40 | 12-1M 20 · 6M 12 · 1M 8 |
| 추세 | 25 | 200MA 이격 10 · 골든크로스 7 · 52주 고점 근접 8 |
| 상대강도 | 15 | QQQ 대비 63일 초과수익 |
| 리스크 | 10 | 20일 변동성 6 · 120일 최대낙폭 4 |
| 거시 적합성 | 10 | 금리·리스크 국면 × 세그먼트 듀레이션/베타 |

**12-1 모멘텀** = 최근 1개월을 제외한 12개월 수익률(`closes[-22] / closes[-253] − 1`).
직전 한 달을 빼는 이유는 단기 반전(mean reversion) 노이즈를 걷어내기 위해서다.

**거시 적합성 공식**

```
macro = 5 − 3 × 금리압력 × 듀레이션 + 2 × 리스크선호 × 베타      (0~10으로 절단)
금리압력  = clip(TNX 60일 변화율 / 15%, −1, +1)
리스크선호 = (SPX 200MA 위 ±0.5) + (VIX < 20 이면 +0.5, VIX ≥ 28 이면 −0.5)
```

세그먼트별 듀레이션·베타는 `data/nasdaq-universe.json` 의 `segments` 에 있다.
소프트웨어(1.30)가 가장 금리 민감, 통신/방어(0.40)가 가장 둔감하다.

## 4. 신호 분류

| 신호 | 조건 | 의미 |
|------|------|------|
| **CORE** | 70점 이상 + 골든크로스 + 갭 캡 아님 | 핵심 편입 |
| **SATELLITE** | 60점 이상, 조건 일부 미달 | 편입하되 성격은 위성 |
| **EXIT** | 12-1 모멘텀 < 0 **또는** 200일선 아래 **또는** 갭 4회 이상 | 편입 금지 · 보유 중이면 청산 후보 |
| **WATCH** | 60점 미만 | 관찰만 |

## 5. 점프 리스크 필터

바이오의 임상 발표에 해당하는 것이 나스닥에서는 **실적 갭**이다.
최근 120거래일 중 일간 ±8% 이상 움직인 횟수를 센다.

- **2~3회** — 편입은 하되 비중을 캡의 50%로 축소
- **4회 이상** — 점수와 무관하게 편입 제외(EXIT)

---

## 6. 포지션 사이징 — 켈리 기준

포지션 크기가 이 전략의 **유일한 리스크 관리 수단**이다(손절선을 쓰지 않는다).

```
f* = (p·b − q·l) / (b·l)
   = (0.45×0.45 − 0.55×0.30) / (0.45×0.30) = 0.278   ← 풀 켈리 27.8%
1/4 켈리 = 6.9%  → 종목당 캡 (3~12%로 절단)
최대 그로스 = 6.9% × 8종목 = 55.6%
```

가정: 이기면 **+45%**, 지면 **−30%**(실적 갭 + 추세 붕괴), 승률 **45%**.
풀 켈리는 파산 확률을 감수하는 값이라 실무에서 쓰지 않는다 —
가정이 조금만 틀려도 과베팅이 되므로 1/4만 쓴다.
가정을 바꾸려면 `data/nasdaq-universe.json` 에 `kelly` 항목을 넣으면 된다.

```json
{ "kelly": { "win_rate": 0.45, "win_payoff": 0.45, "loss_gap": 0.30, "divisor": 4 } }
```

### 배분 규칙

```
비중 = 켈리 캡 × (1 + 0.25 × 점수기울기) × 레짐 투자비중
```

- 점수 기울기는 편입 종목 중 최저 −1 ~ 최고 +1 → 캡의 ±25%만 움직인다
- **서브테마(세그먼트)당 최대 2종목** — 한 테마 몰빵 방지
- 점프 리스크 종목은 캡의 50%
- 남는 몫은 전부 현금 (갭·급락 버퍼)

## 7. 아키타입 — AI를 어떻게 쓰는가

같은 'AI 수혜주'라도 리스크의 성격이 다르다. 배분이 한 유형에 쏠렸는지 따로 본다.

| 유형 | 정의 | 예시 |
|------|------|------|
| **A 내재화** | 자체 칩·모델·데이터로 스택을 안으로 | MSFT, GOOGL, META, AMZN |
| **B 외주** | AI를 사서 쓰는 쪽 — 해자가 약함 | ADBE, INTU, COST, TMUS |
| **C 인프라 공급** | 칩·장비·EDA — 누가 이기든 과금 | NVDA, AVGO, ASML, SNPS |
| **D AI-네이티브** | AI 자체가 실적 서사 — 서사 리스크 100% | PLTR, APP, DDOG, CRWD |

## 8. 반증 조건

전략이 틀렸다고 인정할 기준을 미리 적어 둔다(사후 정당화 방지).
**둘 이상 동시 충족 → 테마 배분을 절반으로 줄인다.**

1. QQQ가 200일선 아래로 이탈 → 레짐 강등
2. 유니버스 200일선 상회 비율 < 40% → 모멘텀 폭 붕괴, 신규 편입 중단
3. 유니버스 평균 12-1 모멘텀 < 0 → 추세 추종 전제 훼손
4. 10Y 60일 +15% 이상 급등 → 롱듀레이션(소프트웨어·D) 비중 축소
5. VIX 28 이상 → Risk-Off 방어 배분
