# 3층 구조 (Three-Layer Portfolio Structure)

> 윌리엄의 포트폴리오 뼈대. knot.e의 모든 판단은 "이 신호가 어느 층에 영향을 주는가?"로 귀결된다.

```
        ┌───────────────────────────────────────────────┐
  3층   │  청팀 (성장주)                                  │
        │  고베타 · 고성장 · 할인율 민감                   │
        │  예: NVDA, PLTR, PL, RDW                        │
        ├───────────────────────────────────────────────┤
  2층   │  백팀 (실물 인프라)                             │
        │  산업재 · 원자력 · 희토류 · 데이터센터 · 방산    │
        │  예(후보): BWXT, MP, VRT, LEU, UUUU             │
        ├───────────────────────────────────────────────┤
  1층   │  현금 (실탄)                                    │
        │  급락 시 매수 여력 · 방어력                      │
        └───────────────────────────────────────────────┘
```

## 각 층의 역할

### 1층 — 현금 (Cash / 실탄)
- **역할:** 에너지·원자재 급락, 시장 조정 때 **싸게 살 실탄**.
- **판단 연결:** "1층 현금이 있으면 → 급락 때 LEU, MP를 싸게 살 수 있다."
- **리스크:** 너무 많으면 순환매 상승을 놓침.

### 2층 — 백팀 (실물 인프라)
- **역할:** 순환매(경기회복 전반)·구조적 수요(SMR, AI 전력, 방산, 리쇼어링)의 수혜. 포트폴리오의 **중심 추(錘)**.
- **자격 판정:** `w12-filter.md` 6개 필터. Tier 1 = 5/6 이상.
- **편입 타이밍:** 지정학 프리미엄이 빠져 가격이 눌릴 때가 매수 기회(구조적 수요는 그대로).
- **후보:** BWXT(원자력), MP(희토류), VRT(데이터센터 전력/냉각), LEU·UUUU(우라늄).

### 3층 — 청팀 (성장주)
- **역할:** 상승장·금리인하 국면의 **엔진**. 할인율 민감.
- **취약점:** 3층만 있으면 → AI 뉴스에 NVDA가 흔들리고, 금리 우려에 PL·RDW가 빠질 때 **방어할 게 없다**. → 그래서 1·2층이 필요.
- **보유:** NVDA(원칙 45), PLTR(원칙 46), PL, RDW.

## 왜 3층인가 — 핵심 논리
> 3층만 있으면 방어가 없다. 2층 백팀이 있으면 순환매에서 같이 오르고, 1층 현금이 있으면 급락을 기회로 바꾼다.
> **각 층은 서로 다른 매크로 국면에서 작동한다.**

## 목표 배분 (Tara 조정 대상 — 기본값)
> 아래는 **시작 기본값**이며 윌리엄의 확정 수치가 아니다. Tara가 조정한다.
> `config/settings.json`의 `target_allocation`에서 바꿀 수 있다.

| 층 | 팀 | 기본 목표 비중 | 현재 상태 |
|----|-----|--------------|-----------|
| 1층 | 현금 | 20–30% | 실탄 확보 |
| 2층 | 백팀 | 30–40% | **편입 작업 시작 단계** |
| 3층 | 청팀 | 30–40% | 보유 중 |

## 현재 국면 메모 (2026-07)
- 금리인하 기대 확대 → **3층 청팀 우호적**.
- 순환매가 산업재·인프라로 확산 → **2층 백팀 편입 타이밍 개선**.
- 에너지·원자재 차익실현으로 백팀 후보 가격 눌림 → **매수 기회 관찰**.
